# Treetracker Database Documentation

This folder contains documentation for the Treetracker database system, including legacy schema analysis, new schema design, and domain migration strategy. Created as part of [Issue #158: Data Overview, Schema, and Dictionary Development](https://github.com/Greenstand/Greenstand-Overview/issues/158) to support data documentation & domain migration.

For migration overview, see [`domain_migration/domain_migration_overview.md`](domain_migration/domain_migration_overview.md). For detailed schema references, use the docs in `legacy/` and `new/` folders.
